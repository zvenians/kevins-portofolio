# Performance record

Implemented: one RAF loop, delta-time cap, bounded spring velocity, adaptive DPR/detail, visibility handling, WebGL context loss/restoration, Canvas2D fallback, reduced motion and sampled `frameAverageMs`/`frameP95Ms` data attributes.

Average/p95 frame time, FPS, long tasks and memory were not measured on representative desktop/mobile hardware. No Lighthouse or FPS score is claimed.
