## Capture and publishing guidance

- Update a screenshot only after checking the corresponding public page.
- Preserve real UI content: resize or compress as necessary, but do not invent interface elements or add fake usage statistics.
- Avoid displaying personal data or private administrative screens.
- Keep the screenshot visually representative of the repository and make its source URL easy to find.
- Review outdated captures when the project changes materially; do not claim that an older image is a real-time preview.

These images support the portfolio's case-study presentation. They do not certify the current deployment's availability, correctness, or security.
